# КРИТИЧЕСКИ ВАЖНО! СОЗДАНИЕ НОРМАЛИЗИРОВАННЫХ ПОЛНОТЕКСТОВЫХ ИНДЕКСОВ
## 1. поместить в ch_init/01_sync.sql (создание функции после перезагрузки контейнера)
CREATE OR REPLACE FUNCTION normalize_text AS (s) ->
    replaceRegexpAll(
        lower(
            replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(replaceRegexpAll(
                replaceRegexpAll(s, '-', ' '),
            'ü', 'u'), 'ö', 'o'), 'ä', 'a'), 'ß', 'ss'), '[éèêë]', 'e'), '[àâãå]', 'a'), '[îï]', 'i'), '[ôõø]', 'o'), '[ûù]', 'u'), 'ç', 'c'), 'ñ', 'n'), '[á]', 'a'), '[í]', 'i'), '[ó]', 'o'), '[ú]', 'u'), 'æ', 'ae'), 'ł', 'l'), 'ń', 'n'), 'ś', 's'), 'ź', 'z'), 'ż', 'z'), '[^a-zA-Z0-9 ]', '')
        ),
    ' {2,}', ' ');

## 2. Создавать таблицы с инвертированным индексом
### после перечисления столбцов:
INDEX idx_norm_text tags TYPE text(
        tokenizer = splitByNonAlpha,
        preprocessor = normalize_text(tags)
    ) GRANULARITY 1

## 3. Добавление индекса в существующие таблицы
### заменить <table> на мя таблицы, а <field> на имя индексируемого поля
### 3.1. создание индекса для сущестующей таблицы
#### 3.1.1. сначала сбросить (если есть) сществующий инвертимрованный индекс для поля
ALTER TABLE <table> DROP INDEX idx_norm_text; # подстваить реальное имя индекса 
#### 3.1.2. создание индекса для сущестующей таблицы
ALTER TABLE <table> ADD INDEX idx_norm_text <field> TYPE text(
        tokenizer = splitByNonAlpha,
        preprocessor = normalize_text(tags)
    ) GRANULARITY 1
#### 3.1.3. материализация индекса (индексация существующих данных)
ALTER TABLE <table> MATERIALIZE INDEX idx_norm_text;
